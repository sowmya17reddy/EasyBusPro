# 🚌 EasyBusPro

A modern **Bus Booking Web Application** built using **Flask, Python, SQLite, HTML, CSS, JavaScript, and Jinja2**. EasyBusPro allows users to search buses, book seats, make payments, manage bookings, and view their travel history through a clean and responsive interface.

---

## 📌 Project Overview

EasyBusPro is a web-based bus reservation system developed as part of my internship project. The application simplifies the ticket booking process by providing a user-friendly interface with secure login, bus search, seat selection, payment, and booking management.

---

- 👤 User Registration & Login

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/sowmya17reddy/EasyBusPro.git
```

### 2. Open Project

```bash
cd EasyBusPro
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Application

```bash
python app.py
```

### 5. Open Browser

```
http://127.0.0.1:5000
```
