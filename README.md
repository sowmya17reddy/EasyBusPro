# 🚌 EasyBus Pro – Bus Ticket Booking System

A modern and user-friendly **Bus Ticket Booking Web Application** developed using **Python, Flask, SQLite3, HTML, CSS, and Jinja2**. The application enables users to search for buses, select seats, make bookings, and manage their bookings through an intuitive interface.

---

## 📌 Project Overview

EasyBus Pro is a web-based bus reservation system developed to simplify the ticket booking process. It provides a seamless experience from user registration to booking confirmation while securely storing user and booking information using SQLite3.

This project was developed as part of my internship to gain practical experience in full-stack web development using Flask.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/EasyBusPro.git
```

### 2. Open the Project

```bash
cd EasyBusPro
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Mac/Linux

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Create Database

```bash
python database.py
```

### 7. Run the Application

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000
```
